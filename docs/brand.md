# 江师办品牌规范

本文是「江师办」的品牌唯一事实源：品牌标几何、色彩、各场景的落地参数，以及改动时要同步的文件清单。品牌资产全矢量（仓库里没有图标 PNG，mipmap 只剩 anydpi 的 adaptive-icon XML）。

## 名称

- **中文名**：江师办（校名简称「江师」+ 承自灵感来源「酱紫办」的「办」——把江师的事**办**了）。
- **历史沿革**：原名「女专办」（「女专」致敬江西师大女子专科学校历史）；「女专红」色名沿用至今，见「色彩」表。
- **英文/包名**：不变，`cn.jxnu.nvzhuanban`（历史既定，不随品牌迭代变更）。
- 副标语：**江西师范大学 · 掌上教务**（登录页在用，见 `strings.xml` 的 `login_subtitle`）。

## 品牌标「将成」

即将闭合的粗环（教务事项、一学期的课）+ 缺口处一粒跃出的火花点（办结在即、点亮）。
一条圆头描边 + 一个填充圆，无其他面，任意缩放不糊。

### 母版几何（1024×1024 视口）

| 元素 | pathData | 描边宽 |
| ---- | -------- | ----- |
| 环（缺口朝右上，起 77° 止 13°，逆时针） | `M571.8,272.8 A266,266 0 1 0 771.2,472.2` | 102 |
| 火花点（填充圆） | 圆心 (754.7, 289.3)、半径 71.7 | 无描边 |

- 环：圆心 (512, 532)、半径 266，`round` 线帽。
- 内容包围盒约 x∈[195, 829]、y∈[215, 849]；几何中心 (512, 532)，落版时以视口中心对齐即可（logo.svg 已内置 -20 竖向校正）。
- 安全区核对：最远端点 = 火花点外缘，距视口中心 401；前景缩放 0.68 后 273 ≤ 312 ✓。

### 同步清单（改几何必须五处一起改）

1. `app/src/main/res/drawable/ic_brand_logo.xml` — 应用内裸标（白描边，使用处 tint）
2. `app/src/main/res/drawable/ic_launcher_foreground.xml` — 桌面图标前景（同时是 monochrome 层）
3. `app/src/main/res/drawable/ic_splash_logo.xml` — 启动页图标
4. `docs/assets/brand/logo.svg` — 图标形态（README 头图）
5. `docs/assets/brand/logo-mark.svg` — 裸标形态（文档/印刷）

## 色彩

| 角色 | 值 | 用途 |
|---|---|---|
| **女专红**（品牌锚点色，色名承自旧品牌） | `#A91D34` | 启动页背景（`res/values/colors.xml` 的 `brand_nvzhuan_red`）、M3 浅色主题 primary、白底文档上的裸标 |
| 图标渐变·亮端 | `#B72440` | 桌面图标背景左上 |
| 图标渐变·暗端 | `#8F1226` | 桌面图标背景右下（对角线渐变，中值≈女专红） |
| 深色主题品牌色 | `#FFB3B6` | M3 深色 primary；深色背景上的裸标用它或纯白 |

- 完整 Material 3 色板（由女专红作 seed 派生）在 `ui/theme/Color.kt`，那里是应用内配色的事实源。
- 白标落在女专红上的对比度 ≈ 7.2:1，落在渐变暗端更高；任何新场景保持「白标只放在女专红或更深的底上」。
- 用户开启 Material You 动态取色后应用内主题色随壁纸变化，这是刻意设计——品牌色只锁桌面图标与启动页两个场景。

## 场景参数

| 场景 | 资源 | 关键参数 |
|---|---|---|
| 桌面自适应图标 | `mipmap-anydpi/ic_launcher{,_round}.xml` | 背景=红渐变矢量；前景=白标缩放 0.68、pivot 视口中心（最远端点 = 火花点外缘，缩放后半径 273 ≤ 312 安全区半径，1024 视口坐标）；monochrome 复用前景 |
| 启动页 | `values{,-night}/themes.xml` | 背景=女专红纯色（两种模式同值）；图标=`@drawable/ic_splash_logo`（288dp 画布，内容缩放 0.68，最远端点 273 < 341 圆形可视半径）；浅色/深色**共用同一资源** |
| 登录页 BrandHeader | `LoginScreen.kt` | 88dp 圆角 24dp、底=primary；标 60dp、tint=**onPrimary**（别写死白色——深色主题 primary 是浅粉，白标会没进去） |
| 「关于」弹窗 | `ProfileScreen.kt` `AboutDialog` | AlertDialog `icon` 槽，44dp，tint=primary |
| README 头图 | `docs/assets/brand/logo.svg` | 128px 居中；**落版刻意与桌面图标不同**：scale 0.78 + 竖向 -20 校正（内容几何中心对齐视口中心），比桌面前景的 0.68 更紧凑——是设计取舍，不是漏同步 |

## 使用规则

1. 品牌标是**描边 + 单填充圆**的图形，缩放时按整体缩放，不要单独调描边宽或火花点半径（二者比例是造型的一部分）。
2. 红底场景一律白标；白底场景红标（`#A91D34`）；深色 surface 场景用 `#FFB3B6`。禁止在红底上放红标或引入第三方配色。
3. 桌面图标前景改动后，务必核对新几何最远端点仍在自适应图标 66/108 安全区内（换算：1024 视口坐标下缩放后半径 ≤ 312）。
4. 需要重新视觉验证时，把两条 path 塞进任意 HTML `<svg>`，用无头 Chrome 截图对比圆形/方圆遮罩、48px 小尺寸、themed icon 单色、深浅色八个场景（无需装任何设计工具）。
